# Cheque Printer

Free cheque printing software for Indian bank cheques (SBI, HDFC, ICICI, Axis, Saraswat and other CTS-2010 leaves).

This repository is the public website, served at <https://pri2092.github.io/>.

- [Home](https://pri2092.github.io/)
- [Download](https://pri2092.github.io/download/)
- [Donate](https://pri2092.github.io/donate/)

The cheque-printing application and its layout logic are not in this repository.
